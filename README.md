# scCCVGBen Next.js companion mirror

This repository is the public GitHub Pages mirror for the scCCVGBen Next.js companion site:

<https://peterponyu.github.io/scccvgben-next/>

The canonical source lives in `PeterPonyu/scCCVGBen` under `webapp/`. The source repository validates the static export with `NEXT_PUBLIC_BASE_PATH=/scccvgben-next`; this mirror owns the same-repository Pages deployment workflow. No cross-repository personal access token or deploy token is required.

The Hugo documentation atlas remains published at:

<https://peterponyu.github.io/scCCVGBen/>
